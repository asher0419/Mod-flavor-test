## 自動查詢流程
1. Excel 內建名稱對照先辨認CAS；CAS输入直接核對檢查碼。
2. 優先重讀這個瀏覽器之前成功確認的來源網址；其次用已有頁面對照。
3. 沒有對照或讀取失敗時，以CAS搜尋TGSC，必要時再以英文名稱搜尋。
4. 搜尋回到目錄時，擷取含相同CAS的表格列與Markdown連結，追蹤成分頁。EPI／結構頁的Datasheet連結也可追蹤。
5. 成分頁的CAS及分子式核對通過才採用，TGSC未取得才查Scents and Flavors。
6. 名稱無法唯一確認時顯示已取得有效CAS與分子式的候選，讓你依廠商資料選擇；不自行猜測。

來源只允許兩個指定網站的HTTPS網址；解析範圍、連結追蹤深度與讀取時間有限，不會無限爬站。供應商／用途頁不直接當單體判定來源。未知排版仍可能失敗。

## 保存方式與使用額度
核對成功的完整結果在這個瀏覽器保存7天，不同PDF／Excel共用，不需手動維護對照。成功來源網址也保存，結果過期後可優先重讀該頁。
勾選「重新向來源查詢」會略過結果快取，仍可使用之前成功的來源網址定位。禁用清單或解析版本變更時，不使用舊的分類快取。
本版沒有跨裝置的雲端資料庫；換裝置、無痕模式或清除瀏覽器資料後，會重新建立對照。瀏覽器禁止儲存時不會因此停止查詢。
只有成功的單體結果會保存，查詢失敗、歧義及精油混合物不會當作成功結果保存。
搜索及Extract仍會消耗Tavily額度，自動定位可使用更多請求，但成功後的重複查詢通常可由快取處理。

## 失敗時怎麼處理
- 讀取失敗／逾時：按「重查未完成項目」。成功項目保留，只重新處理失敗項目。
- 搜尋沒找到頁面：先用廠商CAS再查；仍未取得時，找到TGSC或Scents and Flavors的正確資料頁，點該筆「貼來源網址補查」，填網址並按「核對此來源」。
- CAS／分子式核對失敗：同樣貼正確成分資料頁；若網址對應另一CAS，系統拒絕採用，不會列為沒問題。
- 名稱有歧義：畫面列候選名稱與CAS。按候選後，再核對來源；以廠商的具體CAS為準。成功結果會取代該筆未完成結果。
- CAS檢查碼錯誤：核對OCR原文或廠商文件，修改後重查。
- API金鑰／額度問題：檢查Vercel的TAVILY_API_KEY或Tavily帳戶額度；補網址不能保證避開來源讀取限制。
- 精油混合物：需廠商組成清單，逐個成分排查；不能用一個代表分子式判沒問題。這些項目不會被批次重試。

手動來源是少數失敗項目的補救，不是每列必填。當你只給名稱且不能唯一辨認时，不要任意選CAS。
